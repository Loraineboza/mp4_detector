# Детектор объектов в формате MP4

Обнаружение объектов на изображениях и видео с использованием более быстрого R-CNN с магистралью ResNet-50-FPN. Модель обучена на наборе данных PASCAL VOC 2007 и предсказывает классы объектов и ограничивающие рамки.

## Особенности

- Обучите Faster R-CNN, используя пользовательский набор данных PyTorch для PASCAL VOC 2007.
- Отрегулируйте предварительно подготовленную модель Faster R-CNN для 20 классов объектов VOC.
- Проверьте правильность во время обучения и сохраните оптимальные значения модели, основанные на потерях при проверке.
- Выполните логический вывод на одном изображении.
- Обработайте видео кадр за кадром, нарисуйте места обнаружения и сохраните результат в виде файла MP4.
- Используйте CUDA, когда это возможно, в противном случае запускайте на процессоре.

## Model

Детектор основан на `fasterrcnn_resnet50_fpn` от `torchvision`. Ее классификация и ограничивающая рамка для прогнозирования заменены, чтобы соответствовать набору классов ЛОС.

Модель распознает следующие классы:

`самолет`, `велосипед`, `птица`, `лодка`, `бутылка`, `автобус`, `автомобиль`, `кошка`, "стул", "корова", "обеденный стол", "собака", "лошадь", "мотоцикл", "человек", `растение в горшке", "овца", "диван", "поезд`, `телемонитор`.

Класс background включен внутренне, что составляет в общей сложности 21 класс моделей.

Во время вывода по умолчанию отфильтровываются обнаружения с оценкой ниже "0,5". Это пороговое значение может быть изменено в `img_eval.py` и `mp4_eval.py".

## Настройка набора данных

Загрузите и извлеките набор данных **PASCAL VOC 2007**. Код ожидает, что эта структура каталогов относительно корневого каталога проекта :

``текст
VOCdevkit/
VOC2007 └── /
    ├── Аннотации/
    ├── ImageSets/
    │ └── Главная/
    │ ├── train.txt
    │ └── val.txt
    └── Изображения в формате JPEG/
```

XML-файлы аннотаций и файлы изображений должны соответствовать идентификаторам, указанным в `ImageSets/Main/train.txt ` и`ImageSets/Main/val.txt `.

Загрузчик набора данных считывает идентификаторы изображений, загружает изображения и XML-аннотации и возвращает изображения с ограничивающими рамками и метками классов для ускорения R-CNN.

## Тренировка

Из корневого каталога репозитория запустите:

``bash
python train.py
```

В обучающем скрипте используются следующие настройки по умолчанию:

- Размер пакета: `2`
- Количество периодов: до "30"
- Оптимизатор: SGD с поддержкой momentum
- Начальный уровень обучения: `1е-3`
- Планировщик скорости обучения: StepLR, снижающий скорость обучения каждые 5 эпох в 0,1 раза
- Терпение при ранней остановке: 10 эпох без достаточной проверки - снижение потерь
- Минимальная проверка-снижение потерь: 1e-4

Скрипт выводит данные о потерях при обучении и проверке после каждой эпохи. Он сохраняет наилучший словарь состояний модели в:

``текстовая
модель/weights_faster_rcnn_voc.pth
```

Обучение прекращается, когда достигается максимальное количество периодов или запускается ранняя остановка.

Если аргументы не указаны, скрипт использует настроенный путь к изображению по умолчанию и путь к весам, определенный в `train.py`.

Скрипт выводит количество обнаруженных объектов и их классы, показатели достоверности и координаты ограничивающей рамки. Он отображает аннотированное изображение и сохраняет результат в виде:

```

## Вывод из видео

Бежать:

``bash

```

Чтобы указать вес как видео, так и модели:

``bash
python mp4_eval.py путь/к/video.mp4 путь/к/weights_faster_rcnn_voc.pth
```

Если аргументы не указаны, скрипт использует свой настроенный путь к видео по умолчанию и путь к весам, определенный в `train.py`.

Скрипт обрабатывает видео кадр за кадром, рисует ограничивающие рамки и метки классов, отображает обработанные кадры и записывает выходные данные в:

``текстовый
результат_video.mp4
```

Нажмите "q" или "Esc", чтобы остановить обработку раньше времени.

## Вывод данных обнаружения

Каждое обнаружение содержит:

- ** Метку класса** — прогнозируемую категорию объекта.
- **Оценку** — оценку достоверности модели для прогнозируемого класса.
- ** Ограничивающая рамка** — координаты в формате "[x1, y1, x2, y2]", где "(x1, y1)" - это верхний левый угол, а "(x2, y2)" - нижний правый угол.

Пороговое значение оценки определяет, какие обнаружения отображаются. Это не прямое измерение того, насколько точно прогнозируемое поле совпадает с полем для проверки достоверности.
